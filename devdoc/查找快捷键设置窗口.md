## 总结

PulseView 的通道背景颜色机制如下：

1. **默认模式（colored_bg=true）**：每个通道背景色 = 该通道信号颜色 + 8% 不透明度（`ColorBGAlpha = 8 * 256 / 100`），信号颜色从 `LogicSignalColors[10]` 或 `AnalogSignalColors[8]` 数组中按通道索引循环选取。

2. **灰色交替模式（colored_bg=false）**：通道背景在 `rgba(0,0,0,10%)` 和 `rgba(0,0,0,15%)` 之间交替。

3. **亮/暗主题差异**：主要体现在高电平填充色和光标填充色上，通道背景色本身不随主题变化（它取决于信号颜色），但因为暗色主题的 Base 色是 `#2A2A2A`，而亮色主题的 Base 色通常是白色，所以半透明背景叠加后的视觉效果会不同。

4. **分组（Group）** 没有独立的背景填充色，只有边框线颜色 `#555753`。

5. 该项目**没有**专门的 "card" 或 "卡片" 式背景颜色概念，通道背景是直接在 viewport 绘制区域中通过 `paint_back()` 填充的矩形。
