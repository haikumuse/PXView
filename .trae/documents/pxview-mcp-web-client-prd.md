## 1. 产品概述

PXView MCP 网页客户端 — 一个 AI 驱动的逻辑分析仪控制界面。用户通过自然语言对话控制 PXView 逻辑分析仪（采集信号、解码协议、导出数据），并实时看到 AI 正在执行哪些操作。
- 目标用户：嵌入式开发者、固件工程师、硬件测试人员
- 核心价值：无需写脚本，用自然语言即可完成信号采集→解码→分析全流程

## 2. 核心功能

### 2.1 功能模块
1. **聊天面板**：自然语言对话，AI 自动调用 MCP 工具控制逻辑分析仪
2. **设备状态面板**：显示连接的设备信息、采集状态
3. **设置面板**：配置 LLM API 端点和 MCP 服务器地址

### 2.2 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 主页面 | 聊天面板 | 对话输入、AI 回复、工具调用卡片（可折叠）、解码结果表格 |
| 主页面 | 设备状态面板 | 设备名称、USB 类型、工作模式、采集状态指示灯 |
| 主页面 | 设置面板（抽屉） | baseURL、apiKey、model、MCP 服务器地址输入框 |
| 主页面 | 顶部栏 | Logo、连接状态灯、设置按钮、新对话按钮 |

## 3. 核心流程

用户输入自然语言 → LLM 分析意图 → LLM 返回 tool_calls → 前端调用 MCP 工具 → 返回结果给 LLM → LLM 继续分析或返回最终回复 → 渲染结果

```mermaid
flowchart TD
    "用户输入" --> "发送给 LLM"
    "发送给 LLM" --> "LLM 返回 tool_calls?"
    "LLM 返回 tool_calls?" -->|"是"| "显示工具调用卡片（进行中）"
    "显示工具调用卡片（进行中）" --> "调用 MCP tools/call"
    "调用 MCP tools/call" --> "更新卡片状态（成功/失败）"
    "更新卡片状态（成功/失败）" --> "结果回传 LLM"
    "结果回传 LLM" --> "LLM 返回 tool_calls?"
    "LLM 返回 tool_calls?" -->|"否"| "显示 AI 文本回复"
    "显示 AI 文本回复" --> "检测解码结果?"
    "检测解码结果?" -->|"是"| "渲染解码结果表格"
    "检测解码结果?" -->|"否"| "等待用户下一条消息"
```

## 4. 用户界面设计

### 4.1 设计风格
- **主题**：深色科技风，匹配 PXView 桌面应用的暗色主题
- **主色**：#0D1117（背景）、#1C2333（卡片）、#58A6FF（强调色/链接）、#3FB950（成功）、#F85149（错误）
- **字体**：JetBrains Mono（代码/数据）、Source Han Sans（中文正文）
- **布局**：左侧聊天（70%）+ 右侧设备面板（30%），顶部状态栏
- **按钮风格**：圆角矩形，半透明背景，hover 发光效果
- **图标**：Lucide React 图标库

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 主页面 | 聊天面板 | 深色背景，消息气泡（用户蓝色/AI灰色），工具调用卡片带状态色条，输入框底部固定 |
| 主页面 | 设备面板 | 右侧窄面板，设备信息卡片，状态指示灯（绿/黄/灰），采集进度条 |
| 主页面 | 设置抽屉 | 从右侧滑入，表单输入框，保存按钮 |
| 主页面 | 顶部栏 | Logo 左对齐，连接状态灯 + 设置图标 右对齐 |

### 4.3 响应式
- 桌面优先（1280px+）：双栏布局
- 平板（768-1279px）：设备面板可折叠
- 移动端（<768px）：全屏聊天，设备面板底部抽屉
