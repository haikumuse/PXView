1. **构造函数** — 使用初始化列表将三个 timer 指针置为 `nullptr`，并连接 `QCoreApplication::aboutToQuit` 信号到 `flushPendingSaves()`
2. **`SaveFrame()`/`SaveApp()`/`SaveHistory()`** — 改为防抖（debounce）版本：首次调用时创建 `QTimer`（单次触发），每次调用 `start(2000)` 重置 2 秒倒计时，超时后才执行实际保存
3. **`doSaveFrame()`/`doSaveApp()`/`doSaveHistory()`** — 执行实际的 `QSettings` 写入操作（原 Save 方法的逻辑）
4. **`flushPendingSaves()`** — 检查每个 timer 是否活跃，若活跃则停止 timer 并立即执行对应的 `doSave*()`，确保应用退出前不丢失未保存的配置

### 设计要点

- **防抖机制**：连续多次调用 `Save*()` 时，只会在最后一次调用后 2 秒执行一次实际写入，避免频繁磁盘 I/O
- **安全退出**：`aboutToQuit` 信号确保应用关闭时，所有待保存的配置都会被立即刷写到磁盘
- **QTimer 无父对象**：由于 `AppConfig` 不是 `QObject`，timer 创建时不传 parent，由单例生命周期管理
