### 1. 左侧蓝色提示条 + 圆角矩形 hover 来自哪里

这来自 **Windows 原生样式**（QWindowsVistaStyle）。Qt 在 Windows 上默认使用系统原生主题渲染，会为 `QListWidget` 的选中项绘制蓝色左侧指示条和圆角矩形 hover 效果。

在 [applicationpardlg.cpp:1728-1737](file:///c:/Users/admin/Downloads/DSView-main_2026_4_27cppnb/PXView/pv/dialogs/applicationpardlg.cpp#L1728-L1737) 中，虽然设置了 `NavListDelegate` 去掉了 `State_MouseOver`，但这只阻止了 Qt 层面的 hover 状态，**Windows 原生渲染引擎仍然会绘制蓝色指示条**。

QSS 中没有为 `#settingsNavList` 定义任何样式，所以它完全回退到 Windows 原生渲染。要覆盖它，需要在 QSS 中为 `#settingsNavList` 添加自定义样式来替代原生渲染。

### 2. 样式树形图标能不能删

可以。`_style_category_tree` 是 `QTreeWidget`，当前没有设置 `setRootIsDecorated(false)`，所以会显示分支装饰图标（来自 [theme.qss:1035-1060](file:///c:/Users/admin/Downloads/DSView-main_2026_4_27cppnb/PXView/themes/theme.qss#L1035-L1060) 中定义的 `branch_closed`/`branch_open`/`stylesheet-vline` 等 SVG 图标）。

由于这个树只有顶级项没有子项，这些图标完全没必要。只需加一行：

```cpp
_style_category_tree->setRootIsDecorated(false);
```

加在 [applicationpardlg.cpp:654](file:///c:/Users/admin/Downloads/DSView-main_2026_4_27cppnb/PXView/pv/dialogs/applicationpardlg.cpp#L654) 的 `setHeaderHidden(true)` 后面即可。要我改吗？
